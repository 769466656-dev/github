# AI 量化交易训练营

本仓库用于管理课程案例、策略代码、可复现的数据库结构与少量教学示例图。

## 上传边界

- 提交：源代码、SQL 建表/迁移脚本、脱敏样本、说明文档和经过挑选的示例图。
- 不提交：`.env`、密钥、交易账户、完整数据库、原始行情、虚拟环境、缓存和本地备份。
- 每个案例独立提交；提交前先检查 `git status` 和暂存区。

## 目录

- `database/`：数据库结构、迁移脚本和管理文档。
- `docs/`：数据字典和学习说明。
- 各周目录：保留原始课程布局；当前首批受管案例为第三周的 TA-Lib 技术指标库。

## 快速开始

1. 复制案例的 `.env.example` 为本机 `.env`，填写自己的连接信息；该文件不会被 Git 跟踪。
2. 按 `database/README.md` 创建数据库并依次执行迁移。
3. 运行相应案例代码。运行产生的大型数据和临时输出应保留在本机。
